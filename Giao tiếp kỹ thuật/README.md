# 📐 Module M04: Giao tiếp kỹ thuật & CAD (Technisches Zeichnen & CAD)

**Địa điểm học:** Phòng máy tính CAD  
**Công cụ phần mềm:** Autodesk AutoCAD 2024 for Mac (Autodesk Education)  
**Tiêu chuẩn quy chuẩn:** DIN ISO 128 (Tiêu chuẩn bản vẽ kỹ thuật quốc tế)  

---

## 🎯 1. Mục Tiêu Học Phần
* Làm chủ ngôn ngữ kỹ thuật thông qua bản vẽ: Quy ước khổ giấy (A4, A3), khung tên, tỷ lệ (*Maßstab*), nét vẽ cơ bản (nét thấy đậm, nét khuất đứt, nét tâm gạch-chấm).
* Phương pháp biểu diễn hình học: Các hình chiếu vuông góc trực giao (góc chiếu thứ nhất - First Angle Projection), hình chiếu phụ, hình cắt (*Schnittdarstellung*) và mặt cắt.
* Dung sai kích thước và bề mặt: Kích thước danh nghĩa, giới hạn trên/dưới, dung sai hình học (GD&T) theo chuẩn DIN ISO 2768.
* Thành thạo phần mềm CAD 2D/3D phục vụ gia công cơ khí chính xác.

## 📖 3. Thuật Ngữ Kỹ Thuật (Fachbegriffe)

| Tiếng Việt | Tiếng Đức (*Deutsch*) | Tiếng Anh (*English*) |
|:---|:---|:---|
| Bản vẽ kỹ thuật | **die Technische Zeichnung** | Technical drawing |
| Hình chiếu | **die Ansicht / Projektion** | Orthographic view |
| Hình cắt / Mặt cắt | **der Schnitt** | Section view |
| Kích thước | **das Maß / die Bemaßung** | Dimensioning |
| Dung sai | **die Passung / Toleranz** | Fit / Tolerance |
| Bán kính | **der Radius ($)** | Radius |
| Đường kính | **der Durchmesser ($\varnothing$)** | Diameter |
