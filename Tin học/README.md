# 💻 Module M07: Tin học & Tự động hóa (Informatik & Automatisierung)

**Địa điểm học:** Phòng máy tính trung tâm  
**Môi trường kỹ thuật:** macOS native, Python 3.14, Terminal zsh  

---

## 🎯 1. Mục Tiêu Học Phần
* Thành thạo xử lý số liệu kỹ thuật, phân tích dữ liệu và trình bày báo cáo kỹ thuật chuyên nghiệp.
* Rèn luyện tư duy thuật toán (*Algorithmisches Denken*), cấu trúc dữ liệu và logic điều khiển.
* Xây dựng các kịch bản tự động hóa tác vụ (*Automation Scripts*) bằng Python: Xử lý file, bóc tách dữ liệu từ web, hỗ trợ quản lý học tập.

---
