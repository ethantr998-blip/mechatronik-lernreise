* Rèn luyện tư duy thuật toán (*Algorithmisches Denken*), cấu trúc dữ liệu và logic điều khiển.
* Xây dựng các kịch bản tự động hóa tác vụ (*Automation Scripts*) bằng Python: Xử lý file, bóc tách dữ liệu từ web, hỗ trợ quản lý học tập.
